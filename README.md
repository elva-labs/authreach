# AuthReach

Native macOS menu-bar app that watches your inboxes and surfaces incoming one-time passcodes for instant copy — tray menu, auto-copy, notifications, a global-shortcut HUD, and a loopback-only local API for scripts.

**Status: work in progress.** Native Swift port of the AuthReach prototype; Gmail (OAuth) support first, generic IMAP planned.
